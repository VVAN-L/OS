### 功能模块：Trap 上下文恢复与 Trap 入口功能

**负责人：** 2411858-王钟岳

#### 模块功能描述

**需要实现/修改的函数：**

```c
RESTORE_ALL
__alltraps
```

**功能说明：**

完成 Trap 从“进入内核”到“返回原执行流”之间的底层上下文管理；

保持“Trap frame 布局、上下文保存与恢复、函数调用约定、Trap 返回状态”之间的一致性。

对外的接口：Trap 发生以后，系统应能够通过 \_\_alltraps 建立完整的 Trap frame，并将其作为 struct trapframe \* 传递给：

```c
void trap(struct trapframe *tf);
```

trap() 返回以后，应能够进入 \_\_trapret，完成上下文恢复并通过 sret 返回。

### 功能模块：中断与异常处理功能

### interrupt_handler 函数：

**负责人：** 2412934-王海沛

#### 模块功能描述

**需要实现/修改的函数：**

```c
void interrupt_handler(struct trapframe *tf);
```

**功能说明：**

本模块位于 Trap 入口和统一返回路径之间，接收保存了处理器现场的 trapframe，完成中断原因分类及相应处理。主要场景包括 S 态时钟中断、其他已定义的软件/时钟/外部中断，以及无法识别的中断。

与其他模块的交互如下：trap_dispatch 根据 cause 最高位调用本函数；本函数通过 clock_set_next_event 预约下一次时钟事件，通过 ticks 维护次数，通过 print_ticks 输出统计，通过 sbi_shutdown 请求关机。未知中断调用 print_trapframe 输出现场。正常处理后返回调用方，由汇编恢复现场。本模块不实现 exception_handler，仅为其提供声明以满足分发代码的声明需求。
